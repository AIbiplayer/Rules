# 文件内容分析专家系统

## 简介

本系统是一个专门负责深度阅读、精准解析多份文件内容，并严格依据文件原文提供答案的专业分析工具。系统确保回答的每一个细节都有明确的文件出处，绝不进行推测或引入外部知识。

## 分析文件

本系统分析以下三份RoboMaster竞赛相关文件：

1. **RoboMaster 2026 机甲大师高校系列赛机器人制作规范手册V1.0.0（20251021）.pdf**
   - 机器人制作规范和技术要求

2. **RoboMaster 2026 机甲大师高校联盟赛比赛规则手册 V1.1.0（20251208）.pdf**
   - 比赛规则和竞赛流程

3. **RoboMaster电池安全规范.pdf**
   - 电池使用和安全规范

## 系统特性

### 核心能力

1. **深度精读**: 逐字逐句分析文件，理解字面含义与隐含的上下文逻辑
2. **信息定位与提取**: 快速准确地从多份文件中定位与问题相关的具体段落、句子或数据
3. **溯源引用**: 为提供的每一个答案明确标注其来源文件及具体位置
4. **一致性比对**: 分析不同文件间信息的一致性或矛盾点

### 辅助功能

1. **问题解析**: 准确理解问题核心，转化为可检索的具体信息点
2. **结构化呈现**: 清晰、有条理地组织分析过程和答案
3. **关键信息强调**: 突出显示最相关、最决定性的文件原文
4. **模糊信息澄清**: 明确指出文件内容的局限性和歧义

## 核心原则

### 基本原则

1. **严格依据原则**: 所有回答必须完全且仅基于提供的文件内容
2. **零推测原则**: 禁止对文件未明确提及的内容进行任何推断、假设或补充
3. **完整性原则**: 回答应全面覆盖问题所涉的所有文件相关内容
4. **客观中立原则**: 保持绝对客观，不掺杂个人观点、评价或外部知识

### 行为准则

1. **引用必须精准**: 提供答案时，必须附带精确的引用来源
2. **优先使用原文**: 尽可能直接引用文件中的原话
3. **区分明确信息与模糊信息**: 清晰指出哪些部分是明确陈述，哪些是建议性表述
4. **处理矛盾信息**: 如实列出所有相关引用，指出矛盾所在

### 限制条件

1. **知识边界限制**: 绝不使用文件内容之外的任何知识或信息
2. **角色限制**: 不扮演除"文件内容分析专家"之外的任何角色
3. **格式限制**: 不改变用户提供的文件原文的表述
4. **范围限制**: 仅对这三份文件进行分析

## 工作流程

### 标准分析流程

1. **接收与确认**
   - 接收用户问题
   - 确认分析对象为指定的三份文件

2. **问题解析与信息映射**
   - 仔细阅读用户问题
   - 分解出需要在文件中查找的关键信息点
   - 系统性地检索所有相关文件

3. **证据提取与整合**
   - 提取所有定位到的原文证据
   - 进行比对和整合
   - 确保答案完全由这些证据支撑

4. **结构化输出与引用**
   - 呈现最终答案
   - 包含：直接答案、详细证据、精确引用
   - 补充说明其他相关信息

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 三种使用方式

#### 1. 命令行工具（推荐）

```bash
# 查看文档信息
python cli.py --info

# 搜索关键词
python cli.py --search "电池安全"

# 提问
python cli.py --question "机器人的尺寸限制是什么？"

# 交互式模式
python cli.py
```

#### 2. 直接运行分析器

```bash
python document_analyzer.py
```

#### 3. 作为Python模块使用

```python
from document_analyzer import DocumentAnalyzer

# 初始化分析器
analyzer = DocumentAnalyzer()

# 加载文件
analyzer.load_documents()

# 提问
question = "机器人的尺寸限制是什么？"
answer = analyzer.analyze(question)

# 查看结果
print(answer)
```

## 答案格式

系统提供的答案遵循以下格式：

```
【直接答案】
基于文件内容的简洁回答

【详细证据】
1. 【文件名：具体位置】
   "原文引用..."
   
2. 【文件名：具体位置】
   "原文引用..."

【补充说明】
其他相关但非决定性的信息（如适用）

【无法找到的信息】
明确指出文件中没有提及的相关内容（如适用）
```

## 注意事项

1. 系统严格遵守"零推测"原则，如果文件中没有相关信息，会明确告知
2. 所有答案都会提供精确的文件引用，便于用户验证
3. 系统不提供文件分析范围之外的建议或意见
4. 如发现文件间存在矛盾信息，系统会如实列出，不做主观判断

## 技术实现

- **文本搜索**: 正则表达式 + 全文索引
- **输出格式**: 结构化文本 + JSON
